# Legacy XML stackup files

The XML stackup files in this folder are legacy files, provided for compatibility with existing models such as the examples in the [workflow](../../workflow) folder.

| File | Description |
|---|---|
| `SG13G2.xml`, `SG13G2_200um.xml` | SG13G2 with substrate |
| `SG13G2_200um_backsideGND.xml` | SG13G2 with backside metal |
| `SG13G2_nosub.xml` | SG13G2 without substrate, for structures shielded by a ground metal |
| `SG13CMOS5L*.xml` | the same variants for SG13CMOS5L |

These files are for gds2openEMS only, do not use them with gds2palace.

The latest stackup files can be found in the [latest/IHP](../latest/IHP) folder, with a table of which latest file replaces each legacy file. **For new models, it is recommended to use the XML stackup files from the [latest/IHP](../latest/IHP) folder.**
